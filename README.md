# 大棚湿度监测与浇水预警小工具 (C语言)

这是一个用于模拟大棚/盆栽土壤湿度监测的简单程序。输入预设的 5 组湿度数值，程序会自动判断并输出该地块是否需要浇水。

**代码局限性**：
- 目前湿度数据是硬编码（写死）在代码里的，不支持运行后手动输入。
- 只处理单轮的一维数组数据，不处理传感器实时数据流。
- 判断逻辑目前是单一的阈值（<30），不考虑不同植物对水分的不同需求。

## 使用说明
本项目使用 C 语言编写，无需安装额外第三方库。
1. 确保你安装了 C 语言编译器（如 GCC）或使用集成开发环境（如 Dev-C++, Code::Blocks 等）。
2. 将代码保存为 `moisture_check.c`。
3. 编译并运行代码，程序会自动读取代码中预设的数组，并在控制台输出判断结果。

## 核心逻辑与设计
- **为什么选择数组批量处理？** 因为在实际监测场景中，往往需要同时查看多个传感器节点的数据。使用 `int moisture[5]` 数组配合 `for` 循环，代码结构更清晰，未来如果需要增加到 10 个、100 个节点，只需要修改数组长度即可。
- **为什么设定 30 作为阈值？** 这是一个基于常识设定的经验值（具体应根据植物种类调整）。设定低于 30 为缺水，高于等于 30 为充足。这是为了保证在土壤完全干透前提前预警。
